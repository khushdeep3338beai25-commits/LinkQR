# 🔗 LinkQR — Free QR Code Generator

LinkQR is a free, responsive, browser-based QR code generator that lets users convert website URLs into QR codes and download them as PNG images. It features a simple, user-friendly interface and works without login or a backend.

## ✨ Features

- 🔗 Generate QR codes from website URLs
- 📥 Download QR codes as PNG images
- ✅ URL validation
- 📱 Responsive design for desktop and mobile
- ⚡ Fast and easy to use
- 🔒 Browser-based processing with no backend
- 🆓 Completely free to use

## 🛠️ Technologies Used

- **HTML5** — Page structure
- **CSS3** — Styling and responsive layout
- **JavaScript** — URL validation, QR generation, and PNG downloads
- **QR Code Library** — QR code generation via CDN

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.
4. Enter a valid website URL.
5. Click **Generate QR Code**.
6. Click **Download PNG** to save your QR code.

**Note:** An internet connection is required to load the QR code library from the CDN.

## 🔐 Privacy

LinkQR processes URLs directly in your browser. It does not require an account, login, or backend server.
