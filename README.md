# LinkQR — Free QR Code Generator





A responsive, browser-based QR code generator. Enter a website URL, generate a QR code, and download it as a PNG for free.



## Run it
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Paste a URL and click **Generate QR code**.
4. Click **Download PNG** to save it.

The QR generation library is loaded from a CDN, so an internet connection is needed when opening the page. Links are processed in your browser; there is no login or backend.

## Files


- `index.html` — page structure
- `style.css` — responsive styling
- `script.js` — validation, QR generation, and PNG download
